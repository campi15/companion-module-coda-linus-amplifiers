## CODA Audio Linus DSP Amplifier Companion Module

This module controls Coda Audio DSP Amplifiers via UDP. 

### Configuration

- **Target IP**: The IP of the Coda Amplifier.
<!-- - **Target Port**: The default port is set to 3000. The amplifiers will only receive commands at this port, but this might change later on.  -->
- **Target Port**: The target port is set to 3000 on all Linus amplifiers, so this is not able to be changed.
- **Enable Device Polling**: Enable device polling to receive feedback for variables used by this module.
